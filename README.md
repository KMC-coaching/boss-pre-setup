# BOSS Setup

The one-step installer that prepares a student's computer for their Authority Operating
System, before they have anything installed and before their GitHub account is connected.

It is published here, publicly, for exactly one reason: a student has to be able to
install it before they can reach anything private. Nothing proprietary lives in this
repo. It puts standard tools in place, signs the student in to their own account, and
brings down the system they were separately given access to. The operating system itself,
and everything that personalizes it, lives elsewhere and is not public.

## For students

Inside Claude, add this marketplace and install the **boss-setup** plugin, then say:

> set up my computer

That is the whole instruction. You will not be asked to open a terminal or type a
command. You will be asked to sign in to your own GitHub account, accept the invitation
you were emailed, and approve a couple of things on your phone - those three are yours
because nobody else can do them for you.

## What it does

1. Settles what your Claude is allowed to do on your computer, so it stops asking you
   about every step
2. Reads what is already on the machine
3. Puts Git and the GitHub tool in place, without ever needing your computer password
4. Walks you through signing in
5. Confirms you can reach your system
6. Brings your system down onto your machine
7. Hands off to the system's own setup and stops
