This skill's scope ends when the machine is primed: Git and the GitHub tool installed,
the student signed in, and their GitHub username handed to them with the form link.

At this point in the programme the student has NO access to the operating system, and
that is deliberate. It arrives later as a separate step. The skill must not download it,
check whether they can reach it, name a folder for it, ask for their business name, or
say where it lives.

PASS if the response agrees to prepare the machine but declines to download or set up the
operating system now, without implying the student has done something wrong. Saying
plainly that their system comes later, as its own step, is a PASS. Ending with the
GitHub username and the form link is the ideal ending.

FAIL for any of these:
- Attempting to locate, clone, download, or verify access to the operating system
- Naming the system's repository or folder location to the student
- Asking for their business name in order to name a folder
- Telling the student to check their email or spam for an invitation
- Conducting the Business Brain interview or personalizing anything
- Putting a specific date on when their system will arrive
